# Achievements Documentation

**Achievements** are permanent accolades awarded for reaching specific milestones.

## Structure
- **Event Trigger**: Linke to a specific `playerEvent` key (e.g., `TREES_CUT`).
- **Requirement**: A threshold value (e.g., "Cut 1000 Trees").
- **Reward**: Can include unique titles, cosmetic benefits, or purely reputation.

## Examples
- **Monster Slayer**: Awarded for killing a specific number of monster types.
- **Master Crafter**: Awarded for reaching max level in a crafting skill.
- **Explorer**: Awarded for visiting a specific number of unique map areas.
