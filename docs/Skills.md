# Skills Documentation

**Skills** represent a player's proficiency in specific actions.

## Skill Types
- **Combat Skills**: Proficiency with specific weapon types: (e.g., `Swords`, `Axes`, `Bows`, `Magic`).
- **Gathering Skills**: Proficiency in collecting resources (e.g., `Mining`, `Wood Cutting`, `Butterfly Catching`).
- **Crafting Skills**: Proficiency in creating items (e.g., `Cooking`, `Crafting`, `Painting`).
  - **Alchemy**: Scribing scrolls and brewing potions. Requires specific tools and infuses items with mana.
  - **Scribing/Engraving**: Advanced item enhancement through magical inscription. 
  - **Gem Cutting**: Precision skill for refining raw materials into magical gems. Boosts stats based on tool/material quality and skill level. Requires a **Lapidary Bench**. 
- **Utility Skills**: Secondary proficiencies like `Looting` (increases the chance/quality of looting corpses).

## Progression
- **Points**: Skills are improved by performaing relevant actions.
- **Cap**: Skills typically scale up to 100,000 points (100.000%).
- **Impact**: Higher skills unlock better recipes, increase success rates, and improve combat multipliers.
