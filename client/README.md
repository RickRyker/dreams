# Dreams of Nowhere Else and Beyond Frontend

The Dreams of Nowhere Else and Beyond (nickname "Dreams") frontend is a real-time web client built with React, Vite, and PixiJS for high-performance tiled-map rendering.

## Key Features
- **PixJS Viewport**: Utilizes PixiJS for smooth rendering of large tiled maps, providing a responsive and immersive gaming experience.
- **Real-Time Communication**: Connects to the server via WebSockets for real-time updates on game state, player actions, and world events.
- **Modular Architecture**: Designed with a modular structure to allow for easy expansion and maintenance, supporting future features and content updates.
- **Cross-Platform Compatibility**: Accessible on various devices and screen sizes, ensuring a wide reach for players.

## Getting Started

```bash
npm install
mpm run dev
```
